Clinic Appointment System v2
 Project Overview

Clinic Appointment System v2 is a web-based appointment scheduling system designed to help users book and manage clinic visits with ease.

The system includes user authentication (Login / Register), allows patients to select a date and time for appointments, shows all booked appointments, and prevents duplicate or past-date bookings. Additionally, an admin page displays all appointments for administrative review.

This project was developed as a Graduation Project to practice full stack web development, UI design, and form validation.

 Goals

Provide a clean and functional clinic appointment platform

Build user authentication (login & registration)

Allow users to book appointments with date and specific time

Prevent duplicate time bookings and past dates

Display appointments in organized table format

Include simple Admin view for monitoring

Use front-end technologies only (HTML, CSS, JavaScript)
